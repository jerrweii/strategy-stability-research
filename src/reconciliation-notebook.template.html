01 / Input contract

One stable key, ten explicit fields

Both CSV files require trade_id, strategy, symbol, side, UTC entry and exit timestamps, quantity, entry and exit prices, and fees. Duplicate or empty IDs fail closed.

Expected CSV · Actual CSV

02 / Comparison rules

Small differences remain visible

  • Identity drift: strategy, symbol, or side disagrees for a shared key
  • Timing drift: more than $TIMING_TOLERANCE seconds
  • Price drift: more than $PRICE_TOLERANCE bps at entry or exit
  • Fee drift: more than $$${FEE_TOLERANCE}
  • Quantity must match exactly within floating-point tolerance
